Simple Checkout for OpenCart 4.1.x
==================================

1. Admin > Extensions > Installer
2. Upload simple_checkout.ocmod.zip (or place it in system/storage/marketplace/)
3. Click Install (blue install icon) next to "Simple Checkout"
4. Extensions > Extensions > choose type "Modules"
5. Find "Simple Checkout" > Install (green +) > Edit > Status Enabled > Save
6. System > Users > User Group > Administrator: grant Access + Modify for Simple Checkout
7. Refresh theme cache (Dashboard gear icon)

Test: storefront checkout as guest; after Continue on address, shipping/payment auto-fill when only one option exists.

Uninstall: disable module, Uninstall module, then Installer > Uninstall extension package.
